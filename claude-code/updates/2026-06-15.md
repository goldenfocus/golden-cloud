## What's new
- **New page `/en/advisor.md`**: "Escalate hard decisions with the advisor tool" — pair your main model with a stronger advisor model that Claude consults at key moments during a task.
- **Updated `/en/zero-data-retention.md`**: description now clarifies ZDR is "available to qualified accounts on Claude for Enterprise" (previously implied it was available to all Enterprise accounts).

## Removed
- No pages removed; one description revised (ZDR, see above).

## Workflow-relevant notes
The advisor tool (`/en/advisor.md`) is new and potentially workflow-shifting: if you run complex multi-step tasks, pairing your primary model with a stronger advisor at decision points could change how you configure agents in `~/.claude/CLAUDE.md`. Worth reading the page to see if it applies to your SDK usage or daily Claude Code sessions.

The ZDR wording change (`qualified accounts`) is a scoping clarification, not a policy change — no action needed unless you assumed ZDR was universally enabled for your Enterprise plan; if so, verify your eligibility.

## Workflow-relevant notes
**TypeScript SDK V2 is removed, not just deprecated.** If any project code or CLAUDE.md references the V2 session API (`send`/`stream` patterns), migrate immediately — `/en/agent-sdk/typescript-v2-preview.md` is now a tombstone page.

**Prompt caching doc is worth reading before editing CLAUDE.md.** `/en/prompt-caching.md` documents that CLAUDE.md edits don't apply mid-session (cache boundary), and that model switches bust the cache. If Yan frequently edits CLAUDE.md during a session and wonders why Claude ignores the change, this explains it. No rule in CLAUDE.md needs changing, but it's good to know.

**New sessions doc** (`/en/sessions.md`) covers `--from-pr` to resume the session that created a PR — potentially useful if Yan monitors PRs across devices (pairs with Remote Control).

**Fast mode now defaults to Opus 4.7.** Week 20 note says fast mode runs Opus 4.7 by default. If CLAUDE.md or any config pins a fast-mode model, check it still applies.

No other defaults shifted this week.

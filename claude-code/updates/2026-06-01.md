# Claude Code docs update — 2026-06-01

## What's new
- **New page** `/en/large-codebases.md` — Monorepo and large codebase setup: nested CLAUDE.md files, sparse worktrees, code intelligence, per-package skills.
- **New page** `/en/security-guidance.md` — `security-guidance` plugin: Claude reviews its own code changes for vulnerabilities inline, in the same session.
- **New page** `/en/workflows.md` — Dynamic workflows: Claude writes a script to orchestrate many subagents; rerunnable. Targeted at codebase audits, large migrations, cross-checked research.
- **Week 22 (May 25–29)** `/en/whats-new/2026-w22.md` — Claude Opus 4.8 support, dynamic workflows shipped, security-guidance plugin, fast mode on Opus 4.8 at lower price.
- **Week 21 (May 18–22)** `/en/whats-new/2026-w21.md` — Auto mode on Pro + Sonnet 4.6, `/usage` now shows skill/subagent/MCP server breakdown, new `/code-review` command.
- `/en/agents.md` description updated: "isolated worktree sessions" replaced with "dynamic workflows" as a parallel-work option.
- `/en/claude-directory.md` now lists `workflows` among items read from `.claude` (alongside skills, commands, subagents, rules, auto memory).
- `/en/ultrareview.md` — command renamed from `/ultrareview` to `/code-review ultra`.
- `/en/agent-sdk/hosting.md` — expanded description now covers subprocess architecture, session persistence, scaling, observability, and multi-tenant isolation for Docker, Kubernetes, and sandbox providers.
- `/en/agent-sdk/plugins.md` — description updated: "commands" dropped, "MCP servers" added as a plugin extension surface.

## Removed
- `/en/desktop-changelog.md` — Desktop changelog page removed from index.

## Workflow-relevant notes
**`/ultrareview` → `/code-review ultra`** (`/en/ultrareview.md`): If `~/.claude/CLAUDE.md` or any project CLAUDE.md mentions `/ultrareview`, update it to `/code-review ultra`.

**Dynamic workflows** (`/en/workflows.md`): New first-class primitive for multi-subagent orchestration. If your CLAUDE.md describes a manual fan-out pattern (spawn N subagents by hand), there may now be a cleaner built-in approach worth adopting.

**`security-guidance` plugin** (`/en/security-guidance.md`): New plugin that runs security review inline. If you have a custom post-edit hook doing security checks, evaluate whether this plugin replaces it.

**`workflows` in `.claude` directory** (`/en/claude-directory.md`): `.claude/` now officially hosts a `workflows/` subdirectory. Worth checking if any docs or CLAUDE.md notes about `.claude` structure need updating.

**Monorepo setup** (`/en/large-codebases.md`): New dedicated page. If you work in a monorepo, this page likely consolidates guidance that was previously scattered.
